
# Nexus Dashboard

A modern, responsive web application dashboard built with HTML, CSS, and JavaScript.

## Features

- Responsive sidebar navigation
- Dashboard statistics and project progress
- Interactive performance chart
- Project creation and status filtering
- Task completion tracking
- Light and dark themes
- CSV report export
- Browser Local Storage for saved preferences,
  task completion, and projects

## Technologies

- HTML5
- CSS3
- JavaScript
- Chart.js
- Font Awesome
- Git and GitHub

## Getting Started

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using a local development server,
   such as the VS Code Live Server extension.
4. Use the dashboard to explore its features.

An internet connection is needed to load the external
fonts, icons, and Chart.js library.

## Data and Limitations

This project uses demonstration data and does not connect
to a real backend or database.

Project data, task completion states, and theme preferences
are stored locally in the browser where supported.

## Future Improvements

- Backend integration and authentication

## Project Purpose

Created as a frontend development portfolio project
to demonstrate responsive UI design, JavaScript DOM
manipulation, event handling, data rendering, and
browser storage.
